# Seetee 系列术语表

用于《反物质飞船》《反物质辐射》后续章节的跨章统一译名。

## 固定标题译名

- `Seetee Ship` -> `反物质飞船`
- `Seetee Shock` -> `反物质辐射`

## 人名

- `Nicol Jenkins` / `Nick Jenkins` -> `尼科尔·詹金斯` / `尼克·詹金斯`
- `Jane Hardin` -> `简·哈丁`
- `Jean Lazarene` -> `让·拉扎雷恩`
- `Martin Brand` -> `马丁·布兰德`
- `Jim Drake` / `Drake` -> `吉姆·德雷克` / `德雷克`

## 地名与组织

- `Freedonia` -> `弗里多尼亚`
- `Pallasport` -> `帕拉斯港`
- `Solar City` -> `太阳城`
- `Adonis` -> `阿多尼斯`
- `Seetee, Inc.` -> `Seetee 公司`
- `Interplanet Corporation` -> `星际公司`

## 技术词

- `seetee` -> `反物质`
- `contraterrene` -> `反物质的`
- `terrene` -> `普通物质的`
- `seetee bull` -> `反物质公牛`
- `paragravity` -> `副重力`
- `testing gun` -> `测试枪`
- `drift` / `contraterrene drift` -> `漂移带` / `反物质漂移带`
- `seetee marker` -> `反物质信标`
- `seetee shock` -> `反物质辐射`

## 风格规则

- 正文优先采用自然汉语叙事，不做逐词硬译。
- 同一术语一旦确定，后续章节不随意摇摆。
- 原文只有章节序号、没有章节副标题时，不额外杜撰副标题。
