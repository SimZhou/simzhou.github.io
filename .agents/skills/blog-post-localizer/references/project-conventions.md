# 项目约定

在本仓库中对文章做多语种化时，先阅读此参考。

## 文章目录结构

- 博客文章通常使用 Hugo page bundle。
- 一个目录里通常包含：
  - `index.zh-cn.md`
  - `index.en.md`
  - 同目录共享的图片文件
- 操作对象是整个目录，而不是单个 markdown 文件。

## 语言文件命名

- 遵循 `index.<lang>.md`。
- 本仓库现有示例包括 `index.zh-cn.md` 和 `index.en.md`。
- 在与其它语言文件相同的目录中创建目标文件。

## 结构保真

- 保持相同的 front matter 键集合、markdown 小节顺序和 shortcode 布局。
- 翻译文本，不翻译结构。
- 不要重命名或移动本地图片文件。
- 不要把基于 shortcode 的图片写法改成 raw HTML。

## 图片与 Shortcode 规则

- 优先原样保留现有 `{{< image ... >}}` 和 `{{< compare-images ... >}}` 块，只在需要时翻译其中面向读者的文本字段。
- 保持 page bundle 资源文件名不变。
- 如果源文章已经使用项目级 shortcode，则继续沿用。

## 已知易错点

- 带相对路径 `<img src>` 的 raw HTML 在多语言输出里很脆弱。
- 如果源文章已经使用稳定的 shortcode 方案，应原样保留，不要改回 raw HTML。

## 已有目标文件时的策略

- 当 `index.<target-lang>.md` 已存在时，把它视为待优化草稿，而不是唯一事实来源。
- 将它与其它语种文件对照，修复遗漏、误译和不自然表达。
- 如果用户明确要求更像目标语种母语作者写的博客，可以在不新增事实的前提下，适度优化标题、摘要、导语和段间过渡，让成文语气更自然。
- 用优化后的结果原地替换目标文件。
